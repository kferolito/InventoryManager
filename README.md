# Inventory Manager

A simple command-line inventory management application written in C++. This project was created to practice Git version control while developing a functional application.

## Features

- Add new inventory items
- Remove items from the inventory
- Search for inventory items
- Display the current inventory
- Track item categories, quantities, and prices

## Build and Run

From the project root, compile the application:

```bash
g++ -std=c++17 src/main.cpp -o inventory_program
```

Run the application:

```bash
./inventory_program
```

## Version Control

Git was used throughout development to track changes and organize work. The project includes:

- Meaningful commits documenting individual changes
- Feature branches for independent functionality
- Branch merging to integrate completed features
- Merge conflict resolution when two branches modified the same section of code
